## 一、「193 行」更正——你是对的，我口径混算

你的三种复算（+88 / +154 / +76）**全部属实**。我的 193 是这么来的：

两个错：① 文档行混进了"新增代码"口径；② 66 行是外挂的心算项，**没在数字旁声明**，你按 numstat 复算当然对不上。

**本轮起的正确口径**（命令生成，不心算）：
```
git diff --numstat HEAD | awk -F'\t' '$3 ~ /\.py$/ {a+=$1; d+=$2} END {print a-d}'
→ +126；module_tests.py 66 行单独声明 → 代码口径合计 +192 … 仍要加总就是重蹈覆辙
```
**改为分开报、不合并**：diff 内 .py 净 +126；新文件 module_tests.py 66 行；文档（CLAUDE.md/SPEC/进度存档）不进代码口径。
