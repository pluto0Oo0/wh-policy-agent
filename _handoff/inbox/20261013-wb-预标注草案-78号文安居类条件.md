**原文（一个字不改，供核对）**：

> 「取得普通高校（包括教育部认可的境外高等院校）全日制大专以上学历、毕业6年以内、本通知公布之日起在汉就业创业并正常缴纳社会保险、家庭在汉无自有住房的高校毕业生，在资格有效期内，租住人才租赁房的，按照不高于市场租金的70%缴纳租金，累计减免期限不超过3年。其中，全日制博士研究生、全日制硕士研究生分别免缴2年、1年租金，免租金额每月分别不超过2000元、1500元。本通知公布前留汉的同等条件大学毕业生，现租住人才租赁房且租期未满3年的，在资格有效的剩余期内，按照不高于市场租金的70%缴纳租金。」

**拆成 6 重（对应 SPEC §3.4，逐项核对）**：

| 重 | 规则 | 判定要点 |
|---|---|---|
| 1 | 租金 = 市场租金 × ≤70% | "不高于"——**≤ 不是 =**，实际折扣由各区房源定，**engine 应输出区间或 UNKNOWN** |
| 2 | 累计减免 ≤ 3 年 | 封顶 |
| 3 | 博士免缴 2 年 | 分层·时长 |
| 4 | 硕士免缴 1 年 | 分层·时长 |
| 5 | 免租金额：博士 ≤2000 元/月、硕士 ≤1500 元/月 | 分层·金额封顶 |
| 6 | 续期（jzwh 解读版有："最多可再延长2年，延长期内按市场价"）——**78 号文原文没有这句**，来自其他文件。**纵切先不做第 6 重，标注 `未核实`** | 跨文档依赖 |

**`_08` 的 formula 草案（伪代码，供 CC 实现）**：

```python
if education == "博士":   免租期 = 2 年; 免租封顶 = 2000 元/月
elif education == "硕士": 免租期 = 1 年; 免租封顶 = 1500 元/月
else:                     免租期 = 0;    免租封顶 = 0
# 免租期后：市场租金 × 70%（≤）
# 全部累计 ≤ 3 年
# 市场租金本身 UNKNOWN → amount 输出需含"以实际房源为准"标记
```
