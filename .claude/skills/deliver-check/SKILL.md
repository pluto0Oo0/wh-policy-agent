# 交付前自检（强制）

## 铁律

**不许直接回答"完成了"。先看下面的真实检查结果，再决定说什么。**

判断标准（本项目 CLAUDE.md 第 10 条的原话）：

> **如果所有者没有盯着看，这个流程自己能不能发现错误？不能，就是没做自检。**

---

## 第 1 步：真实检查结果（已自动执行）

> 下面这段用的是 Claude Code 的 dynamic context injection：
> 系统**先执行命令、把真实输出插进来**，再交给我。
> **我看见的就是真实结果，不是我自己推测的。**

> ⚠️ **必须用项目自己的 .venv 解释器**，不能用裸 `python`——
> 实测本机 PATH 里的 `python` 指向 `D:/Python312/python`（全局），
> 不是本项目的 `.venv`。用错了会跑出"明明装了却说没装"这类怪问题。

```!
cd "${CLAUDE_PROJECT_DIR:-.}" && "./.venv/Scripts/python.exe" scripts/check_deliver.py 2>&1; _code=$?; echo ""; echo ">>> EXIT_CODE=$_code"
```

> ⚠️ **`_code=$?` 必须紧跟在 python 命令后面、不能隔任何命令**（2026-09-26 自查两次才修对）：
>
> **错误写法**：`... 2>&1; echo ""; echo "EXIT_CODE=$?"`
> → `$?` 取的是中间那个 `echo ""` 的退出码，**恒为 0**。
> 结果：明明"未通过"，却显示 `EXIT_CODE=0`。
>
> **正确写法**：`... 2>&1; _code=$?; echo ""; echo "EXIT_CODE=$_code"`
> → **先把退出码存进变量，再做别的**。
>
> **这个坑我踩了两次**：第一次是管道（`| tail` 吃掉了退出码），
> 第二次是中间插了个 `echo`。**两次都是"我在验证退出码时反而把它弄丢了"。**

**规则**：

- **退出码非 0 就是没通过。** 不许跳过，不许说"这些问题不影响"。
- 修完重跑，**直到退出码 0 或每个未通过项都有明确理由**。
- 例外：`[假对比]` 和 `[行数]` 这两类，如果确实需要人工处理（比如 expected_samples
  必须人打开浏览器填），**必须明确说出来"这一条我处理不了，需要所有者做"**，
  而不是含糊过去。

## 第 2 步：脚本查不了的部分（必须自己回答）

脚本只能查可枚举的问题。下面三条**必须逐条回答**：

### 1. 这批数据 / 这个模块，目的达到了吗？

**必须真的去数，不能"看起来有"。**

> 反例（2026-09-24 实测踩过）：
> 抓了 90 条政策，自检全绿，宣布完成。
> 第二天才发现——**90 条里只有 1 条是目标政策**。
> 原因是选错了源层级（市政府本级 vs 部门发文）。

### 2. 如果有检查失败，失败的真实原因是什么？

⚠️ **布尔判断会骗人。**

> 反例（2026-09-26 实测）：
> `文号检索 = 0 命中` 有两种完全不同的原因——
> **(a) 源不对** / **(b) 翻页不够**。
> 我当时判定是 (a)，实际是 (b)：武政办〔2022〕78号 就在 `bgtwj` **第 10 页**。
>
> **查失败原因，不要只看失败与否。**

### 3. 有没有"和常识不太一样"的地方，但脚本没报警？

有就列出来，**哪怕不确定**。不确定的地方往往藏着真问题。

## 第 3 步：输出格式

必须输出三件事：

1. **`check_deliver.py` 的完整输出**（不截断）
2. **第 2 步三个问题的逐条回答**
3. **本次新增的检查项** —— 如果这次踩了新坑，**把它加进 `scripts/checks/`**，
   **不要只写进 markdown 文档**。
   > 理由：**文档里的规则会被忘，脚本不会。**
   > 这是本项目最贵的一条教训：CLAUDE.md 第 10 条"要自检"写完当天就被违反了两次，
   > 而写成脚本后，第一次跑就抓出了三个真问题。

## 本项目的数据专项红线

| # | 红线 | 由来 |
|---|---|---|
| 1 | **先看有没有我要的内容，再看新不新，最后才看好不好爬**（顺序不能反） | `zcwd` 好爬但内容不对口；`jzwh` 内容对口但停更 2023 |
| 2 | **必须区分「现行有效」和「只是旧」** | 政策文件默认长期有效；怀疑对象是"是否已废止"，不是"发布时间早" |
| 3 | **抓取 0 条 / 条数异常 / 内容长度异常 → 报错**，不许静默返回空 | `index1.shtml` 少个下划线 → HTTP 200 + 18 万字符 + **0 条** |
| 4 | **硬指标失败先查翻页范围**，再下"源不对"的结论 | 78 号文在第 10 页，差点误杀合格源 |
| 5 | 单文件 ≤200 行；禁 `except: pass`；读写显式 `encoding="utf-8"` | CLAUDE.md 第 2 / 8 条 |
