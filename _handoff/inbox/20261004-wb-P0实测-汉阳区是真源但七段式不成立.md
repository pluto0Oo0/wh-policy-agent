## 三、✅ 好消息 3：其实是「三轨并行」，比 SPEC 假设的还多一轨

汉阳区人才安居政策解读原文里，**三条轨道并列**：

| 轨 | 文号 | 条件 |
|---|---|---|
| 武汉市老政策 | `武房规〔2018〕2号` | 毕业 3 年内 + 本市户籍 + 家庭无房 |
| 武汉市新政策 | `武政办〔2022〕78号` | 毕业 6 年内 + 社保 + 家庭无房；70% |
| 🔴 **汉阳区新政策** | **`阳政〔2022〕26号`《知音人才谷政策（试行）》** | **全日制大专以上学历**、毕业 6 年内、在**汉阳区**就业创业 |

**区级加码的实证**（SPEC §3.4 说"市级完全没有"，属实）：
- 门槛更低：**大专**即可（市级未明确大专）
- 免租额度：博士 2000 元/月、硕士 1500 元/月
- 房租要求：整租 ≤2000 元/月、合租 ≤1500 元/月为基数减免
- 社保要求：纳保的人才公寓须正常缴社保 → 缴 **85%**

→ **`applies_to_cohort` 至少要能表达三轨，不是两轨。** SPEC §3.2 需要修订。

## 四、🔴 坏消息 1：汉阳区**没有七段式**（0/10），SPEC §3.3 假设不成立

三篇区级页面（人才安居政策解读 + 两份配租指南）逐一检查：

## 六、⚠️ 纠正 CONTEXT 的一处错误：洪山是**假源**

`/zwgk_38/xxgkml/ggzypz/zfbz1/bzxzfzc/` 在洪山返回 HTTP 200 + 60 条链接，
但内容**全是新闻动态**（大学生戏剧展演、篮球世界杯、烈士纪念日、社区活动、招商盘点）——
**没有一条住房/安居政策**。

→ **同一个路径在不同区指向的东西不一样。**
→ CONTEXT §5 写的"汉阳、洪山实测存在"里，**洪山是假阳性**。
→ 这又是「**抓到东西 ≠ 抓对了东西**」——**这条教训现在是第三次出现了**（78号文在第10页 / rsj 解读不在列表 / 洪山假源）。
