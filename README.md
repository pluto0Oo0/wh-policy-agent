# wh-policy-agent

> 武汉大学生政策条件判定助手 —— 输入个人画像，输出「能享受哪些政策 + 省多少钱 + 依据哪一条 + 还缺什么」。

**状态**：🚧 开发中（Phase 1）

---

## 这个项目解决什么问题

武汉面向大学生的政策散落在市人社局、各区官网、人才工作网等十几个渠道，同一政策在不同区口径不一，已废止的页面从不标注失效。申请人往往不知道自己能享受什么、卡在哪一条。

本系统输入一份个人画像，输出**可解释的判定结果**：

- ✅ 能享受 / ❌ 不能享受 / ❓ 信息不足
- 每条判定附带**政策名 + 文号 + 原文摘录**
- 计算类政策输出**具体金额**
- 信息不足时**主动追问**，而不是硬给答案

---

## 为什么不是"政策问答"

| | 政策问答 | 本项目 |
|---|---|---|
| 市场状态 | 红海 | GitHub 搜 `补贴 资格 大模型` = **0 结果** |
| 对错 | 主观，难评测 | **确定，可自动评测** |
| 检索的角色 | 就是产品 | 只是前置步骤 |

调研发现：15 个相关政策类公开仓库，**没有一个给出准确率数字**。

---

## 技术要点

- **不建向量库**——语料 80-150 条，`BM25 + 元数据过滤` 足够（选型理由见 `docs/SPEC.md` §3.1）
- **判定用纯代码**——可判定的事不交给模型，LLM 只负责抽取
- **人群分层**——2022-06-07 前后适用两套规则（合法的"老人老办法"），"取最新版本"是错的
- **冲突显式暴露**——9 组市区口径冲突，不静默取一个
