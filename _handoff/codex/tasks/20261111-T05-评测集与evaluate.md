### 2. `scripts/evaluate.py`（≤200 行，中文注释，只用标准库）

**必须实现：**

1. 读 `eval/golden_conditions.jsonl`、`data/processed/policies.jsonl`、`eval/eval_cases.jsonl`、`eval/v4_pending.jsonl`
2. **覆盖完整性**：

4. 打印：
   - 总准确率（correct / total）
   - **三类分别的准确率**：`该类正确数 / 该类样本数`（ELIGIBLE / INELIGIBLE / UNKNOWN 分开，**不许只给一个总数**）

   - 失败清单：case_id / expected / got / 缺失字段 / derivation 摘要

5. `--selftest` 故障注入（**必须有**，这是"检查器自己也要被验证"）：

   - 非法 expected 值 → 必须报错
   - 重复 case_id → 必须报错
   - **故意翻转 1 条 expected** → 准确率必须下降，且该条出现在失败清单里
6. 结构性错误（文件缺失 / 0 条 / <50 条 / 未知 policy_id）→ 退出码 1；正常跑完 → 退出码 0

## 四、必须遵守的判定语义（写 expected 前先读）

| 状态 | 含义 | 触发条件 |
|---|---|---|
| `PASS` | 符合 | 画像字段满足比较 |
| `FAIL` | 确实不符合 | 画像字段存在且比较为假 |
| `UNKNOWN` | 信息不足 | 字段缺失 / 计算类缺 `market_rent` / `ambiguity` 非空 |
| `N/A` | 该轨道不适用 | `applies_to_cohort` 不匹配（**不是 FAIL**） |

**汇总规则**：有 FAIL → INELIGIBLE；无 FAIL 有 UNKNOWN → UNKNOWN；全 PASS（N/A 不参与）→ ELIGIBLE。

**两条最容易标错的：**

1. `age < 45` 对硕士/博士**豁免**（`exempt_when`）——50 岁博士是 PASS，不是 FAIL。
2. 老轨道画像（`first_insurance_date < 2022-06-07`）看 78 号文时，`_05`（新政策通道）是 **N/A**，`_10`（老政策通道）才参与判定；反之亦然。
